# Madhav E-commerce Store Sales Dashboard

## Project Objective
The objective of this project is to help Madhav Store track and analyze its online sales across India using an interactive Power BI dashboard.

## Tools Used
- Power BI
- Data visualization
- Data analysis
- Filters and slicers

## Project Overview
This project focuses on building an interactive dashboard to make online sales data easier to explore and understand.

The dashboard uses different visualizations to present sales-related information. Filters and slicers allow users to explore the available data from different perspectives.

## Key Features
- Interactive sales dashboard
- Filters and slicers for data exploration
- Different chart types for visualizing data
- Tables and calculations to support analysis
- Visual exploration of sales performance

## Key Business Questions
- How does sales performance change across the available time periods?
- Which product categories perform well?
- How does sales performance vary across locations in India?
- What patterns can be identified from the available sales data?
